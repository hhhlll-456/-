# Task 12 真机数据复核脚本

`docs/superpowers/analysis/error-mece.md` 里每个"实测幅度"都可由本目录脚本从
`实验/实验数据记录.xlsx` 独立复算。**不含任何估算数**；算不出的写在文档的
《缺口清单 · 3.1 仍缺》里。

## 数据源与结构

`实验/实验数据记录.xlsx` → sheet `data`：每行 100 Hz 原始采样；每个 trial 是一块
原始行（`timestamp` = 块内秒数，编码器计数块内累加、每 trial 归零），块的
**最后一行是汇总行** —— 判据：`trial_ok` 非空（原始列空、`notes` = "汇总行"）。

全批 **84 条**汇总行 = **62 跑通 / 22 失败**；失败行无视觉/里程计对比列。
按动作：直行 31 / 横移 18 / 原地旋转 20 / 斜行 15（跑通：21 / 14 / 15 / 12）。

## 运行

```bash
cd <仓库根>                      # 脚本自己找仓库根，cwd 只影响不了它
PYTHONPATH=~/.local/lib/python3.12/site-packages python3 实验/t12_stats/build.py
```

先跑 `build.py` 生成 `dataset.json`（汇总行整理集，84 行），其余脚本都读它。

## 关键口径（易错处）

- **RUN 段** = 末段四轮 `pwm` **全非零**的连续块。首末差取该段两端。
  斜行按 X 型布局只驱动一个对角对（`pwm_fr=+110 / pwm_rl=−110 / pwm_fl=pwm_rr=0`），
  会被该判据排除，故轮次数是 200 而非 248。
- **轮速** = `Δencoder / C_1rev × 2π / Δt`，`C_1rev = 1276/1270/1276/1274`（FL/FR/RL/RR）。
  编码器只有 A 相 ⇒ 该式只给**幅值**。
- **场地系 → 车体系**：用 `实验/vgt/harness.py` 的 `body_delta_to_field` **反解**
  （该算子是自逆的，但别手推），并断言 `field→body→field` 往返一致；
  再自检"实测方向 == 指令方向"（横移 14/14、平移 47/47 通过）。
- **有符号 ≠ 幅度**：漂移率、比值一类量同时给有符号分布与 `|·|` 分布；
  符号中位近 0 只表示左右各半。
- **原地旋转行的 `dist_diff_pct` 无物理意义**（位移≈0，比值被分母放大），
  统计时分组给。

## 不适用本目录的

- E2 的**稳态**轮速 / 「实测÷查表」比值：本批 RUN 段仅 0.12–0.39 s，与起转死区
  （0.105–0.14 s）同量级，**无一条进入稳态**，取窗换法结果差 ≈1.4×。需 ≥2 s
  恒 duty 复测（= Step 5 复测，满电 + 用户在场）。
- `μ1/μ2`、`k_yaw/b_z`、逐轮 `R_eff_i/C_m_i`：需专门的标定实验。
