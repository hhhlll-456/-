## 1. 为什么偏航腿能独立判 c1

仓库的正运动学（`odometry.integrate_encoders`）只有一处定义 `d_i`：

```
d_i = q_i · 2πR / c1_i
dψ  = (−d0 + d1 − d2 + d3) / (4·LXY)
```

**偏航和平移吃的是同一个 `c1`/`r_eff`。** 原地旋转时运动学要求
`d = (−a, +a, −a, +a)`，四项带符号距离**同号**，于是

```
dψ = (2πR / (4·LXY)) · Σ_i (Δc_i / c1_i)
```

即"总计数 → 偏航角"是一条**只被 `1/c1` 缩放**的直线。所以若 `c1` 真错了 2.7 倍，
偏航必然也错 2.7 倍；偏航腿是**不依赖平移腿**的独立测量。

`yaw_c1.py` 开头的 `verify_formula()` 把这条闭式和 `integrate_encoders` 逐位对比
（差 < 1e-9 rad 才往下走），防止"闭式写错还照样出数"。

⇒ **偏航腿落在同一档**（与平移腿的 1385–1430 / 1185–1224 一起围着 1274），
**不是 1274/2.7 = 472，也不是 1274×2.7。**

### 本轮额外看到的一件事

"只积 D 行"那一列是 **0.46** —— 纯旋转时 `D` 行只覆盖了 **46%** 的实际转角，
剩下 54% 是停车后的自由滑行。这和直行腿的窗口错配是同一个病，但比例不同
（旋转 1/0.46 ≈ 2.2×，直行 ≈ 2.6×）。并入滑行后两条腿都对上了。

`warnings=[]`，32 条 D 行，`sign_ok=True`。

### 为什么这一轮用 `settle_after_done_s=1.0`（默认是 0.4）

判据比的是**两个窗口**，而补读在终点帧**之后**。只有"终点帧那一刻车已经滑停"
两个窗口才对齐；默认 0.4 s 对 300 ms 脉冲不够。这是**测量有效性**的选择，
不是"调到通过"—— 沉降给短只会让 odo 偏大（终点帧早于滑行结束），判据 ① 反而更难达成。

### 车的位置

起手 PnP (89.6, −2.9) → 终了 (15.4, +27.5)，**没有出界**（场地 x∈[−252.5, 252.5]、
y∈[−125.9, 125.9]）。这轮选**后退**就是为了让车落回场地中央、两侧都留余量。
