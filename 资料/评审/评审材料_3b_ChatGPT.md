
所以，我建议把倾斜法作为补充测量，而不是直接取代所有其他方法。

## 五、方法三：制作一个简单的刚性测量平台，解决麦轮接触不稳定的问题

如果你希望尽可能准确地测量四个轮子的载荷，我认为这个方法值得尝试。

它不是改变麦轮本身，而是改变测量装置。

### 5.1 核心思路：让电子秤测量平台的整体载荷

你现在的测量方式是：

麦轮滚子 → 电子秤

接触位置的变化会影响读数。

可以尝试改为：

麦轮滚子 → 刚性承载平台 → 电子秤

例如，在每个电子秤上放置一块足够刚硬、不会明显变形的金属板。金属板的尺寸应足以容纳滚子可能接触的区域。

这样做的目的是让局部接触载荷通过刚性平台传递给电子秤，减少接触位置对读数的影响。

不过，需要强调一个容易忽视的物理问题：

**刚性板不会自动消除电子秤对受力位置的敏感性，也不会保证所有读数完全一致。**

如果电子秤内部存在明显的位置敏感性、平台倾斜或者支撑不均匀，读数仍然可能变化。

因此，实施前需要进行校准。

### 5.2 如何校准？

可以按照下面的步骤操作：

1. 将刚性板放在电子秤上。
2. 使用已知质量的砝码。
3. 分别把砝码放在板的中心、四角以及其他位置。
4. 记录每个位置的读数。
5. 检查读数是否随加载位置变化。

如果同一个砝码在不同位置产生明显不同的读数，那么这套测量装置还不能直接用于高精度的单轮载荷测量。

如果四套装置经过校准后表现良好，再进行整车测量。

### 5.3 更好的方案：采用统一的刚性承载结构

如果你具备简单的加工条件，可以考虑制作一块统一的刚性平台，四个轮子分别作用在四个经过校准的测力点上。

这相当于构建一个简易的四点称重台。

需要注意：

- 四个测力点的高度必须一致。
- 平台不能明显弯曲。
- 各测力点之间不能出现额外的力传递路径。
- 平台不能碰到其他物体。
- 必须考虑滚子产生的水平力，以及测力装置对这些力的响应。

如果你最终发现电子秤本身的精度不够，可以考虑使用四个独立的称重传感器和专门的测量电路。

但我不建议你现在就购买新设备。先验证现有电子秤的重复性，再决定是否升级，成本会更低。

## 六、方法四：先测量每个部件的质量，再通过质量加权计算质心

**对于你最终要建立 URDF 模型的目标，这可能是最值得投入时间的方法之一。**

你的小车通常由底盘、电机、轮子、电池、控制板、支架和传感器等部件组成。

如果你能够分别测量这些部件的质量，并确定它们各自的质心位置，那么就可以直接计算整车的质心。

这个方法不需要知道四个轮子各自承担多少重量。

### 6.1 基本公式

假设整车由 \(n\) 个部件组成。

第 \(i\) 个部件的质量为：

\[ m_i \]

它的质心坐标为：

\[ \mathbf r_i= \begin{bmatrix} x_i\\ y_i\\ z_i \end{bmatrix} \]

那么整车总质量为：

\[ M=\sum_{i=1}^{n}m_i \]

整车质心为：

\[ \boxed{ \mathbf r_c= \frac{\sum_{i=1}^{n}m_i\mathbf r_i} {\sum_{i=1}^{n}m_i} } \]

展开后：

\[ \boxed{x_c=\frac{\sum_i m_i x_i}{M}} \]\[ \boxed{y_c=\frac{\sum_i m_i y_i}{M}} \]\[ \boxed{z_c=\frac{\sum_i m_i z_i}{M}} \]

这三个公式分别给出整车质心的纵向、横向和高度坐标。

### 6.2 举一个例子

假设小车由三个简化部件组成：

| 部件         | 质量   | 质心纵坐标 |
| ------------ | ------ | ---------- |
| 底盘         | 1.0 kg | 0 mm       |
| 电池         | 0.5 kg | 50 mm      |
| 其他电子设备 | 0.5 kg | -20 mm     |

以底盘几何中心为纵坐标原点：

\[ M=1.0+0.5+0.5=2.0\text{ kg} \]

于是：

\[ x_c= \frac{1.0\times0+0.5\times50+0.5\times(-20)} {2.0} \]

得到：

\[ \boxed{x_c=7.5\text{ mm}} \]

这意味着整车质心沿纵向偏离底盘几何中心 7.5 mm。

这只是演示计算方法的示例，并不是你的实际小车参数。

### 6.3 具体怎么测？

我建议你把小车拆分成以下几类：

| 部件类别         | 测量方法   | 质心位置的确定方法                   |
| ---------------- | ---------- | ------------------------------------ |
| 底盘板           | 电子秤称重 | 根据板材形状和均匀性估计，或使用 CAD |
| 四个电机         | 单独称重   | 根据电机外形、轴线及内部结构估计     |
| 四个麦轮         | 单独称重   | 根据轮体几何和材料分布估计           |
| 电池             | 单独称重   | 根据电池外形和内部质量分布估计       |
| 控制板及传感器   | 分别称重   | 根据安装位置和板卡几何估计           |
| 支架、螺丝、线缆 | 分组称重   | 根据实际安装位置估计                 |

这里有一个很重要的细节：

**如果某个部件已经被包含在一个总成的质量中，就不能再重复计算。**

例如，你把电机和轮子作为一个完整的驱动总成称重，那么计算时就不能再次把电机和轮子的质量单独加进去。

如果你能获取底盘的 CAD 模型，可以直接在 CAD 中定义材料密度，计算各零件的质量和质心，再与实物称重结果进行对照。

对于结构复杂、内部质量分布不均匀的部件，CAD 的几何质心不一定等于实际质心。必要时仍然需要实验验证。

## 七、方法五：利用 CAD、SolidWorks 或 Fusion 360 计算质心

如果你的底盘是自己设计的，或者有对应的三维模型，那么可以直接在 CAD 中进行计算。

这个方法特别适合为 URDF 建模做准备。

### 7.1 你需要建立什么？

将小车分解为多个刚体：

- 底盘。
- 四个电机。
- 四个麦轮。
- 电池。
- 控制板。
- IMU。
- 其他支架和附件。

在 CAD 中为各零件设置合理的材料密度，并确保装配位置与实物一致。

然后利用软件的质量属性分析功能，获取：

- 整车质量。
- 整车质心。
- 相对于指定坐标系的质心坐标。
- 绕指定坐标轴的转动惯量。

### 7.2 这个方法的优势是什么？

它不仅可以估计质心，还可以提供 URDF 需要的其他物理参数。

URDF 的惯性描述包含：

- 质量。
- 惯性参考坐标系的位置。
- 惯性张量。

其中，惯性参考坐标系的原点通常应位于相应刚体的质心，而惯性张量描述该刚体对角加速度的抵抗程度。ROS 的 URDF 文档也对这些物理属性作了说明。[GitHub](https://github.com/ros2/ros2_documentation/blob/rolling/source/Capabilities/Simulation/URDF/Adding-Physical-and-Collision-Properties-to-a-URDF-Model.rst?utm_source=chatgpt.com)

所以，从你的最终目标来看，CAD 方法具有很高的价值。

### 7.3 CAD 结果不能直接当作真实值

你需要注意三个问题：

1. CAD 模型可能没有包含所有实际安装的线缆、螺丝和支架。
2. 你可能没有准确设置每个零件的材料密度。
3. 实物装配位置可能与 CAD 中的装配位置存在偏差。

因此，我建议采用以下验证方法：

\[ \text{CAD 质量} \quad\leftrightarrow\quad \text{实物总质量} \]

如果两者差异很大，就需要检查模型中是否遗漏了零件、材料密度是否合理，以及装配是否完整。

**CAD 负责提供几何与惯性估计，实物测量负责验证。** 两者结合通常比单纯依靠其中一种方法更可靠。

# 九、特别注意：质心不是 URDF 的全部

现在我们进一步回到你的最终目标：在 URDF 中仿真麦轮小车。

很多初学者会把重点全部放在质心上，但实际上，URDF 的物理建模还需要考虑其他参数。

我建议你按照以下结构组织测量工作。

## 9.1 几何参数

需要测量：

- 底盘长度和宽度。
- 底盘厚度。
- 四个轮子的轴心坐标。
- 四个轮子的轴线方向。
- 车轮半径及有效滚动半径。
- 车轮宽度。
- 麦轮滚子的安装方向。
- 底盘、轮轴和地面的相对高度。

其中，四个轮子的安装位置和方向对于运动学建模非常重要。

## 9.2 质量与惯性参数

需要获取：

- 整车质量。
- 各个刚体的质量。
- 整车质心。
- 各个刚体的质心。
- 各个刚体的惯性张量。
- 需要时计算整车相对于选定参考点的惯性参数。

对于结构简单的刚体，可以利用几何形状和质量计算惯性；对于结构复杂的总成，可以先通过 CAD 估计，再用实验进行合理性验证。

## 9.3 接触与摩擦参数

麦轮小车的仿真还涉及：

- 轮子与地面之间的摩擦。
- 滚子与地面之间的接触行为。
- 接触刚度与阻尼。
- 滚子与轮体之间的相对运动。
- 轮子几何形状与仿真碰撞模型之间的差异。

这些参数与所用仿真器有关。URDF 主要描述机器人结构、几何和惯性等信息；实际的接触行为和某些物理属性可能还需要仿真器专用配置。

如果只是为了快速验证运动学和控制器，没必要一开始就建立包含每个滚子的高复杂度模型。

如果你希望仿真能够准确复现侧向滑移、接触力和加速度响应，就需要进一步研究麦轮滚子与地面的接触建模。

# 十、四轮速度与底盘速度的转换，不依赖质心测量结果

这是你最初提到的另一个关键问题。

假设：

- \(r\)：车轮有效滚动半径。
- \(L\)：底盘中心到前后轮轴线的纵向距离。
- \(W\)：底盘中心到左右轮轴线的横向距离。
- \(v_x\)：底盘纵向速度。
- \(v_y\)：底盘横向速度。
- \(\omega_z\)：底盘绕竖直轴的角速度。
- \(\omega_{FL},\omega_{FR},\omega_{RL},\omega_{RR}\)：四个车轮的角速度。

对于常见的 45° 滚子布置麦轮底盘，一组常见的逆运动学关系是：

\[ \begin{bmatrix} \omega_{FL}\\ \omega_{FR}\\ \omega_{RL}\\ \omega_{RR} \end{bmatrix} = \frac{1}{r} \begin{bmatrix} 1&-1&-(L+W)\\ 1&1&L+W\\ 1&1&-(L+W)\\ 1&-1&L+W \end{bmatrix} \begin{bmatrix} v_x\\ v_y\\ \omega_z \end{bmatrix} \]

**这只是某一种轮子编号、坐标系和正方向约定下的公式。** 不同的麦轮安装方向、滚子排列、轮速正方向定义可能导致矩阵中的符号发生变化。

在将它用于你的实物之前，必须根据实际安装情况确认各轮的正方向。

该类运动学关系可以参考 ROS 2 对全向轮底盘运动学的说明。[Control ROS](https://control.ros.org/master/doc/ros2_controllers/doc/mobile_robot_kinematics.html?utm_source=chatgpt.com)

这里最值得你记住的是：

- 车轮半径决定轮子角速度与轮缘速度之间的关系。
- 轮子相对于底盘中心的位置决定旋转运动的速度分配。
- 滚子方向和安装布局决定纵向、横向运动的符号组合。
- 质心主要影响动力学，而不是上述理想运动学转换矩阵。

因此，即使你暂时还没有准确测出质心，也可以先测量几何参数，建立运动学模型，并验证四轮速度分配是否正确。

# 十一、针对你的最终目标，我建议采用的完整工程路线

现在把所有内容串起来。

你的项目不是单纯的质心测量问题，而是一个从物理测量到机器人建模，再到控制器调试的完整工程问题。

我建议采用以下顺序。

### 阶段 1：测量几何参数

先确定：

- 底盘尺寸。
- 四轮轴心位置。
- 车轮半径。
- 滚子方向。
- 各部件安装位置。

**暂时不必追求质心的毫米级精度。**

### 阶段 2：确定质量与质心

按照以下顺序实施：

1. 测量整车总质量。
2. 测量主要部件质量。
3. 根据 CAD 或几何估计各部件的质心。
4. 使用质量加权公式计算整车质心。
5. 用四个电子秤的实验结果进行交叉验证。
6. 如果质心高度仍不确定，再设计专门的倾斜测量实验。

### 阶段 3：计算惯性参数

对于每个刚体：

- 先从 CAD 获取惯性张量。
- 如果没有 CAD 模型，则根据合理的几何近似计算。
- 检查质量、尺寸和惯性数值是否一致。

不要把质心位置与转动惯量混为一谈：它们是不同的物理参数。

### 阶段 4：建立 URDF 模型

建立：

- `base_link`
- 四个轮子对应的 link。
- 四个驱动关节。
- IMU 对应的 link 或固定关节。
- 必要的视觉模型与碰撞模型。

然后补充每个刚体的质量和惯性参数。

### 阶段 5：验证运动学

先进行低速实验：

1. 四轮按设计方向转动，验证直行。
2. 进行横向移动，验证麦轮滚子布局。
3. 进行原地旋转，验证角速度方向。
4. 比较编码器估计速度和 IMU 测量的角速度。

如果直行时小车持续偏转，首先检查四轮方向、有效轮径、编码器方向和电机实际转速是否一致，而不是立即增加 PID 参数。

### 阶段 6：建立闭环控制

最后再分别调节：

- 单电机速度环 PID。
- 四轮协调控制。
- 直线运动控制。
- 角度控制。
- 编码器里程计与 IMU 的融合。

你提到的“旋转 30°”，实际上还需要区分角速度控制与角度控制：

- 角速度控制：让小车以指定的角速度旋转。
- 角度控制：让小车最终停在目标角度，例如 30°。

后者需要角度反馈和适当的闭环控制策略，单纯控制四轮以固定速度旋转，并不能保证最终角度精确。
