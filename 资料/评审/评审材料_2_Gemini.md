\## 一、 麦轮小车运动学速度转换方程（正逆解）

对于标准 **X 型排列**的四轮麦轮全向移动底盘，设车体中心在坐标系 $(X, Y)$ 下：

\*   $v_x$：车体纵向（前进/后退）速度

\*   $v_y$：车体横向（左右平移）速度

\*   $\omega$：车体旋转（绕 Z 轴）角速度

\*   $R$：车轮半径

\*   $L_x$：前后轴距的一半

\*   $L_y$：左右轮距的一半（或轴距与轮距之和的一半，取决于参数定义，通常令 $L = L_x + L_y$）

\### 1. 逆运动学（底盘速度 $\rightarrow$ 四轮转速）

已知整车期望运动速度 $(v_x, v_y, \omega)$，求解四个轮子的转速（或线速度 $v_1 \sim v_4$）：

\*   **左前轮 (FL, 1)**：$v_1 = \frac{1}{R} \left( v_x - v_y - (L_x + L_y)\omega \right)$

\*   **右前轮 (FR, 2)**：$v_2 = \frac{1}{R} \left( v_x + v_y + (L_x + L_y)\omega \right)$

\*   **左后轮 (RL, 3)**：$v_3 = \frac{1}{R} \left( v_x + v_y - (L_x + L_y)\omega \right)$

\*   **右后轮 (RR, 4)**：$v_4 = \frac{1}{R} \left( v_x - v_y + (L_x + L_y)\omega \right)$

\### 2. 正运动学（四轮转速 $\rightarrow$ 底盘实际速度）

通过四个轮子的编码器反馈速度 $(v_1, v_2, v_3, v_4)$ 推算底盘当前运动状态：

$$v_x = \frac{R}{4} (v_1 + v_2 + v_3 + v_4)$$

$$v_y = \frac{R}{4} (-v_1 + v_2 + v_3 - v_4)$$

$$\omega = \frac{R}{4(L_x + L_y)} (-v_1 + v_2 - v_3 + v_4)$$

\## 二、 破解麦轮“滚子滑动”下的质心测量难题

你用四个小称直接称重时遇到读数不稳、随滚子角度变化的现象是完全正常的。因为麦轮外周的滚子可以自由旋转，当你把车轮放在称上时，滚子受力会发生滚动，导致接触点发生位移，水平分力无法平衡，从而破坏了垂直压力的真实读数。

要准确测量质心（CoM），可以采用以下三种工程替代方案：

\### 方案 1：机械锁定法（最推荐，简单粗暴）

\*   **做法**：使用**热缩管**套在每个麦轮外面并加热收缩，或者用强力胶带、3D 打印定制的“圆柱形套环”把整个麦轮的滚子**完全锁死**，让它在称重时表现得像一个普通的刚性圆柱轮。

\*   **原理**：消除了滚子的自由度后，四个小称的垂直反力便能真实反映车体各点的重力分布，直接通过公式计算出质心坐标：

​    $$x_c = \frac{L}{2} \cdot \frac{(F_{FR} + F_{RR}) - (F_{FL} + F_{RL})}{F_{total}}$$

​    （其中 $F_{total}$ 为总重量，$L$ 为前后轴距）

\### 方案 2：单点支点法（杠杆平衡法）

如果不想拆卸或改装轮子，可以放弃四点同时称重，改用**单点/双点支点法**：

1. 准备一个固定的刀口支架（或细长棱条），将小车单侧架在支架上，利用单台电子秤测量另一端支撑的力。
2. 根据杠杆平衡原理（$M = F \cdot d$），通过改变小车在支架上的倾斜或支撑位置，分别测出 X 轴和 Y 轴方向的力矩平衡点，从而计算出质心。这种方法不依赖车轮与地面的接触摩擦形式。

\### 方案 3：CAD 质量反算 + 实验微调

\*   **做法**：在 SolidWorks 或 Fusion 360 中对你的小车进行 1:1 三维建模。将电池、电机（TK-ENC-TT-26B）、TB6612 驱动板、GY-25T IMU、ESP32-S3 及车架赋予各自的实际材料密度与重量。

\*   **结果**：CAD 软件会自动计算出整车的质心坐标 $(x_c, y_c, z_c)$ 以及惯性张量（Inertia Tensor）。

\*   **结合 URDF**：在实际写 URDF 的 `<inertial>` 标签时，直接填入 CAD 算出的数值。在后续仿真中如果发现偏航或平移有微小偏差，再通过 PID 或参数微调补偿。

\## 三、 MECE 原理：影响麦轮小车无法理想行进的因素分析

为了帮你在后续调试和生成技术文档时做到**相互独立、完全穷尽 (MECE)**，我们将误差因素划分为以下四个维度：

\```

​       ┌────────────────────────────────────────────────────────┐

​       │             麦轮小车理想行进偏差因素 (MECE)               │

​       └───────┬──────────────┬──────────────┬───────────┬──────┘

​               │              │              │           │

​       ┌───────▼──────┐┌──────▼──────┐┌──────▼─────┐┌────▼─────┐

​       │  1. 运动几何  ││  2. 机械动力  ││  3. 电气执行 ││ 4. 传感环境│

​       └──────────────┘└──────────────┘└────────────┘└──────────┘

\```

1. **运动学与几何因素 (Kinematic & Geometric)**

​    \*   **轮径误差**：四个 TK-ENC-TT-26B 轮子的实际直径存在微小制造公差（如 $\pm 0.2\text{mm}$）。

​    \*   **安装不对称**：轮轴不平行、车体结构轻微变形导致运动学矩阵的 $L_x, L_y$ 理论值与实际不符。

​    \*   **滚子几何畸变**：麦轮滚子并非理想圆柱面，边缘缝隙会导致周期性的位置脉冲扰动。

2. **动力学与机械因素 (Dynamic & Mechanical)**

​    \*   **质心偏离**：电池等重物摆放不正导致四轮正压力不均，摩擦力不等。

​    \*   **摩擦力各向异性**：麦轮斜向滚子在不同方向滑动时的地面摩擦系数存在差异。

​    \*   **传动侧隙与阻尼**：电机减速箱齿轮间隙、联轴器虚位及轴承机械阻尼不一致。

3. **电气与执行因素 (Electrical & Actuation)**

​    \*   **电机死区与非线性**：TB6612 驱动下，低 PWM 时电机无法启动，且左右电机转速-PWM响应曲线不一致。

​    \*   **编码器计数误差**：编码器分辨率有限或存在脉冲丢失、毛刺干扰。

​    \*   **电源压降**：电池电量变化导致四轮输出力矩随时间衰减不一致。

4. **传感与环境因素 (Sensing & Environmental)**

​    \*   **IMU 零偏与安装误差**：GY-25T 的零漂、温度漂移以及安装时的偏角误差。

​    \*   **地面平整度与附着力**：地面微小起伏导致部分车轮瞬间悬空或打滑。

\## 四、 后续建议与 URDF 仿真对接

当你完成上述步骤后，在编写 **URDF** 时，建议重点关注以下两点：

1. **`<inertial>` 标签配置**：将 CAD 算出的 `mass`、`ixx`、`iyy`、`izz` 准确填入基座（base_link），这是做 Gazebo 动力学仿真时小车不翻车、不打滑的关键。
2. **转轮连杆定义**：在 URDF 中将四个麦轮定义为连续关节（continuous joint），并在控制插件（如 `gazebo_ros_planar_move` 或 ros2_control 的 mecanum diff drive plugin）中代入上面推导的正逆解矩阵。
