## 0. 约定与通用准备

### 0.1 坐标与轮序（与 xlsx 一致，不要改）
- **原点** = 四轮轴心在俯视投影下的矩形中心（不是接地点矩形中心——接地点随辊子相位跳、不可复现）。
- **X 轴** = 前进方向；**Y 轴** = 向左为正；**ω** = 俯视逆时针为正。
- **轮序**：1 = 左前 FL，2 = 右前 FR，3 = 左后 RL，4 = 右后 RR。**先贴标签再测量**。
- 已实测几何（本文直接用）：轴距 `L_b = 137.5 mm`（`l_x = 68.75`）；前轮距 `W_bf = 120`（`l_yf = 60`）、后轮距 `W_br = 118`（`l_yr = 59`）；轮外径 `D = 67 mm`；整车质量 `m = 0.697 kg`（四秤合计 697.08 g，重复性 ≈0.06%）。

### 0.2 通用器材清单
| 器材 | 用途 |
|---|---|
| 4 个电子秤（量程 ≥1 kg，分辨率 ≤0.1 g） | 四轮载荷、部件称重 |
| 水平仪（气泡/手机 App 均可） | 台面调平、测倾角 |
| 钢直尺 / 卷尺 / 游标卡尺 | 几何尺寸 |
| 塞尺（0.02–1 mm 片组） | 间隙、共面度 |
| 等高硬垫块若干（5 / 10 / 15 mm，可用叠加） | 倾斜称重、垫平 |
| 小木块 / 挡块 | 倾斜时防麦轮爬行 |
| 标准砝码（50 / 100 g） | 秤的线性与偏心标定 |
| 细绳 + 吊点（螺栓/吊环）+ 垂球或铅垂线 + 相机 | 双线悬吊（z_c 复核） |
| 秒表 / 手机慢动作录像 | 时间常数、转速实测 |
| 记号笔、美纹纸 | 标轮子相位、地面标线 |

### 0.3 总原则
1. **所有质量测量用同一台秤的同一档**，并先按 §6.3 校准；四秤之间读数要互相对得上。
2. **每次记录都注明状态**：是否含电池/配重、轮子相位、温湿度。
3. **同一量的四份拷贝（四轮）一致比单轮绝对值更重要**——极差才是真正的误差源。
4. 矩阵里凡是「进公式的正负号」（辊子朝向、给正占空比转向、正转计数增减），**错一格小车就反着走**，PID 再调也没用，务必逐一核对。

# 第一部分　质心测量（步骤 1–5）

## 步骤 1　冻结平面质心 + 量化「不共面」

**目的**：确认平面质心可冻结、并量出四轮高度差（决定 URDF 每个轮 joint 的 z 偏置）。

**背景结论**（已由三模型评审确认）：四秤法求平面质心 `x_c=ΣNᵢxᵢ/ΣNᵢ`、`y_c=ΣNᵢyᵢ/ΣNᵢ` **在四轮不共面时仍严格成立**——竖直力的力矩只与水平力臂有关，支点高度不进入方程。因此 `(−0.68, −0.15) mm` 可信、≈几何中心，**直接冻结采用，不再重测**。7.1% 的「对角模式」不平衡落在四支点静不定的零空间里，**不是质心偏心**。

**操作**：
1. 按现行方法把车放四秤上，记录 `FL/FR/RL/RR` 四读数。
2. **整车原地水平旋转 180°**（四个轮子换到另外/对角的秤上），再记录一次。
3. 用水平仪 + 塞尺量四个秤台面高度差；用直尺 + 塞尺量四轮底相对同一基准面的高度差（把车放平板上，逐个轮底塞片）。
4. **判据**：
   - 若对角模式**跟着车走**（旋转后对调）→ 是**车体扭转**，按不共面建模。
   - 若对角模式**跟着秤/位置走** → 是**台面或秤**问题，先后把台调平、秤校准再测。
5. **记录**（填入「一次性检查」第 2 行及 URDF）：四轮底相对高度差各多少 mm。

**产出**：URDF 里四个 `wheel joint` 的 z 偏置 = 各轮底实测高度差（不要强行拉平）。

## 步骤 2　质心高度 z_c —— 主测：倾斜称重法

> 目标指标：xlsx「必需参数」B 组 `z_c`（车体不含轮质心高度），当前为空。

**原理一句**：把一端垫高 θ，重力沿斜面分量改变两轴载荷分配；未抬高那对轮的载荷增量直接给出 z_c。

**器材**：4 个电子秤、等高垫块（可取 12 / 24 / 36 mm 三档）、水平仪/角度仪、挡块、直尺。

**符号与约定（务必按此，否则测反）**：
- `L = L_b = 137.5 mm`（轴距）。
- `W = 697.08 g`（整车重量的克力当量，用克做单位可让 z_c 直接得 mm）。
- `θ` = 倾角 = `asin(Δh / L)`，`Δh` = 抬高量。
- **`N_low` = 「没有被抬高、仍贴地」的那一对轮的载荷之和**（这是唯一正确的取法；若你测的是被抬高那对，符号会相反）。

**操作**：
1. **水平态**：四轮都放平，先测一次未抬高那一对轮的载荷和 `N_low0`（同一扭转状态下测）。
2. **垫高**：把**另一对轮**（例如后两轮）用**等高硬垫块**垫起，垫高量 `Δh`；量准 `Δh`（卡尺/叠加垫块）。
3. **防爬（关键）**：麦轮在斜面上极易滚动。在下坡方向、**尽量贴近地面**的位置用挡块顶住车架。
   > 说明：挡块接触点越高，它给车体加的额外力矩越大，引入的 z_c 误差越大；能贴地就贴地。
4. 静置，读 `N_low(θ)`（那一对贴地轮两秤之和）。
5. **一致性自检**：`N_low(θ) + N_high(θ)` 应 ≈ `W·cosθ`。若明显不等 → 车在爬动或秤没放平，重做。
6. 对 `θ ≈ 5°、10°、15°` 三档各做一遍（对应 `Δh ≈ 12、24、36 mm`）。
7. **计算**（这里的 `N` 是未抬高那一对）：
   ```
   z_c = L · [ N_low(θ) − N_low0 · cosθ ] / ( W · sinθ )
   ```
   单位：`L` mm、`W` g、`N` g → `z_c` 直接是 mm。
8. **判据**：三档反算的 `z_c` 应互相接近，**离散 < 10%**；且 `N_low(θ) > N_low0·cosθ`（抬高另一端后，贴地端应加载变重）。

**记录表**：

| θ | Δh (mm) | N_low0 (g) | N_low(θ) (g) | N_low+N_high (应≈W·cosθ) | z_c (mm) |
|---|---|---|---|---|---|
| 5° | 12 |  |  |  |  |
| 10° | 24 |  |  |  |  |
| 15° | 36 |  |  |  |  |

**由「整车 z_c」换算「车体（不含轮）z_c」**（xlsx 要的是后者）：
```
z_body = ( m_total · z_c_whole − Σ m_w,i · z_axle ) / m_body
```
其中 `z_axle = R_eff ≈ 33.5 mm`（轮轴中心离地高）；`m_w,i` 用四轮表里的每轮质量；`m_body = 554.07 g`。

**失败退路**：若小车在斜面上无论如何都压不住（一直爬），改用步骤 3b 的双线悬吊法。

## 步骤 3　z_c 交叉验证

### 3a　交叉验证之一：部件质量加权（便宜、独立）

**器材**：电子秤、游标卡尺、钢尺。

1. 把车**拆分为**：底盘板 / 电池 / 4×(电机+轮) / 主控+驱动 / IMU / 支架线缆，**逐件称重** `m_i`。
   > 注意：若某件已被包含在一个总成里称过，**不能再单独加一遍**（避免重复计入）。
2. 以车体原点为基准，量出每件几何中心的安装坐标 `(x_i, y_i, z_i)`（z 以底盘底面或轴心为基准，全文写清基准）。
3. 计算：
   ```
   z_c = Σ m_i z_i / Σ m_i        （x_c = Σ m_i x_i / Σ m_i，y 同理）
   ```
4. **判据**：`z_c` 与步骤 2 差 **< 20%** 即视为同量级通过（此法误差大，只做量级校验，不追求精度）。

**部件记录表**：

| 部件 | 质量 m_i (g) | x (mm) | y (mm) | z (mm) | 位置来源 |
|---|---|---|---|---|---|
| 底盘板 | | | | | 实测/CAD |
| 电池 | | | | | 实测 |
| 电机 1 (+轮) | | | | | 实测 |
| 电机 2 (+轮) | | | | | 实测 |
| 电机 3 (+轮) | | | | | 实测 |
| 电机 4 (+轮) | | | | | 实测 |
| 主控+驱动 | | | | | 实测 |
| IMU | | | | | 实测 |
| 支架/线缆 | | | | | 实测 |

### 3b　交叉验证之二：双线悬吊法（更可靠，能同时给三维，可选但推荐）

**原理一句**：自由悬挂时，质心必在过吊点的铅垂线上；换第二个吊点再得一条铅垂线，两线交点即质心（含 z）。

**器材**：细绳、两个吊点（顶部螺栓/吊环，方向差别要大）、垂球或铅垂线、相机、钢尺。

1. 选两个**方向差别大**的吊点 A、B（例如 FL 角与 RR 角上方、或 IMU 座与另一角）。
2. 从 A 自由悬挂小车至静止；用**垂球**标出过 A 的铅垂线，并从**两个正交视角**拍照（侧视 + 正视），画面里放钢尺做比例尺。
3. 换 B 重复，同样两视角拍照。
4. 在照片上把两条铅垂线投影到车体坐标系的 x–z、y–z 平面，重建两条 3D 直线，求交点 → `(x_c, y_c, z_c)`。
5. **判据**：两次结果一致（差 <1–2 mm）；`(x_c, y_c)` 应与四秤法 `(−0.68, −0.15)` 吻合（<1 mm）。

**对比小结**：双线悬吊不受滚子接触/摩擦各向异性影响，对低矮小车尤其可靠；倾斜称重法胜在省事但怕爬行。**建议：步骤 2 三档倾斜为主测，3b 悬吊做复核；二者差 <10% 即可采用。**

## 步骤 4　判定 X 型 / O 型

> xlsx「必需参数」第 3 条现填 `X`，但 HANDOFF 记录「尚未确认」。此判定直接决定运动学矩阵的符号，**务必实测坐实**。

**方法 A（几何，快）**：
1. 小车架空或从正下方/正上方拍照（见「拍照清单」P1/P7）。
2. 看四个麦轮的辊子斜向：
   - **X 型**：四个轮的辊子轴线在地面投影呈「X」；相邻两轮的辊子自由方向关于车身轴线对称。
   - **O 型**：同轴（前轴两轮 / 后轴两轮）辊子方向**相同**，呈「+」。

**方法 B（行为，准）**：
1. 低速给**纯横移**指令（例如只给 `v_y`）。
2. 观察：小车应**平移不打转**、方向符合预期。
3. 若平移方向与预期相反或明显边移边转 → 符号/布局判定有误，回到四轮表逐一核对辊子朝向。

**记录**：填入「必需参数」第 3 条 + 「四轮参数表」的「辊子自由方向」「给+占空比转向」「正转计数增减」三列。
> 已录：FL +45°、FR −45°、RL −45°、RR +45°。若为 X 型，用四轮表里给出的标准方程；若判为 O 型，那组方程不成立，需另推。

## 步骤 5　有效半径 R_eff 标定（对 PID 比 CoM 更重要）

> 目标指标：四轮表 `C_1rev_i / C_m_i / R_eff_i`，以及「必需参数」D 组 `(l_x+l_y)/R_eff`。

**器材**：卷尺、≥1 m 直线（地面画线）、记号笔、秒表。

**操作**：
1. **单圈计数 `C_1rev_i`**：在轮子和车架上各画一条记号对齐；手推使该轮**正好转 1 圈**，读编码器计数差值。（或用编码器计数到 `C_1rev` 时确认记号回到对齐。）
2. **每米计数 `C_m_i`**：四轮同速沿直线前进 `D ≥ 1000 mm`，读该轮计数 `N_i`，则 `C_m_i = N_i / D`（单位：计数/mm 或计数/m，统一即可）。正、反各做一次取平均。
3. **有效半径**：
   ```
   R_eff_i = 1000 · C_1rev_i / ( 2π · C_m_i )      （mm）
   ```
4. **判据**：四轮 `R_eff` 差异 **< 0.5–1%**；否则修正运动学矩阵（每轮用各自的 R_eff）。
5. 同法做一次**横移**，检查辊子自由方向的计数一致性。
6. **记录** → 四轮表对应列；再算 `(l_x + l_y)/R_eff` 填「必需参数」D 组。

**另记**：把轮轴中心离地高用卡尺量出，应 ≈ `R_eff`（差 >2 mm 说明量到了悬挂件或轮子不是最低着地点，见「一次性检查」第 20 条）。

# 第二部分　xlsx 其余「还没有数据」的指标 —— 详细测量方法

> 下面按 xlsx 分组逐条给方法。**每条格式：目的 / 器材 / 步骤 / 记录 / 判据。**

## 6. A 组 · 几何（补齐）

### 6.1 轮宽 `t`（必需参数 #14，当前空）
- **器材**：游标卡尺。
- **步骤**：卡尺量轮子两侧面之间的最大厚度（含辊子最外凸点），四个轮各量一次。
- **记录**：`t_1..t_4`，取均值填 #14；四轮离散记备注。
- **判据**：四轮差 ≤1 mm。

### 6.2 四轮共面度与几何自洽（一次性检查 #3、#20、#21）
- **底盘扭转刚度**：把小车**对角两轮**垫起 2 mm，量另**对角**两轮的离地变化量。
- **轮轴心离地高 vs R_eff**：见步骤 5 末。
- **离地间隙 `h_g` 是否承重态**：务必在**四轮着地**状态下量底盘最低点离地（悬空量会偏大，URDF 的 z 会错）。
- **判据**：扭转离地变化 ≤2 mm；轴心高与 R_eff 差 ≤2 mm；`h_g` 承重态 >0。

### 6.3 秤的线性与偏心标定（做所有质量测量的前提）
1. 标准砝码分别放同一秤的**中心、四角、边缘**，各读一次。
2. **判据**：极差 ≤0.5% 满量程 → 合格；否则所有测量都只把载荷放**秤盘中心**。
3. 四秤之间用同一砝码互校，读数应一致（差 ≤0.3%）。

## 7. B 组 · 质量与惯量（补齐）

### 7.1 各部件质量（附录 #22、#24、#25、#27）
- **电机（含减速箱）`m_m`**：拆下逐个称（或用「电机+轮」总成就必须标明含轮）。
- **底盘板 `m_p`**：拆下称。
- **电池 `m_b`**、**主控+驱动 `m_c`**：单独称。
- **判据**：`Σm_i ≈ 697 g`（含电池装配态），差 >2% 说明漏件或重复计入。

### 7.2 绕 Z 轴转动惯量 `I_zz`（必需参数 #19，当前空）
**方法 A（计算，先做）**：
- 逐件算 `I_zz = Σ m_i·(x_i² + y_i²)`（相对质心，含各件自身惯量；块状件自身项很小可略）。单位：g·mm² / 1e9 = kg·m²。
**方法 B（实测，三线扭摆，校核）**：
1. 三根等长细线把一块**轻平台**水平吊起，线下端系在半径 `R` 的圆周、上端系在半径 `r` 的圆周，线长 `L`。
2. 把**已知惯量**的物体（如质量 m₀、半径 r₀ 的均匀圆盘，`I₀=m₀r₀²/2`）放平台中心，测摆周期 `T₀`；再放小车（或车体），测周期 `T`。
3. `I_car = I₀ · (T² − T_platform²)/(T₀² − T_platform²)`（`T_platform` = 空平台周期）。
4. **判据**：A、B 两法差 <30% 即接受（惯量本就难测准）。
- **记录** → #19 与附录 #20/#21（`I_xx`、`I_yy` 用同法或长方体近似）。

## 8. C 组 · 驱动映射（必需参数 #20–27，当前全空）

### 8.1 减速比 `i`（#20）
- **来源**：电机铭牌/手册（TK-ENC-TT-26B V1.2）；无手册则**实测**：手动转输出轴 1 圈，数输入轴（电机轴）转的圈数。
- **记录** → #20。

### 8.2 编码器每转脉冲数 `PPR` 与倍频（#21、#22）
- **PPR**：手册值（单相每转脉冲）。**倍频**：记录是硬件正交 4 倍频、还是 1/2 倍频，或软件计数方式（附录 #45）。
- **记录** → #21、#22；并核对：`C_1rev`（步骤 5）应 ≈ `PPR × 倍频 × 减速比`（若编码器在电机轴上）。

### 8.3 编码器安装位置（#23）
- **步骤**：照片确认编码器磁环/码盘是装在**电机轴**（减速前）还是**输出轴**（减速后）。这决定 `C_1rev = PPR×倍频×i` 还是 `= PPR×倍频`。
- **记录** → #23。

### 8.4 满占空比轮速上限 `n_max`（#24）
- **步骤**：小车架空，四轮给 100% 占空比，用编码器测转速（`rpm = 每秒计数 / C_1rev × 60`），正/反各一次，读每秒稳定值。
- **记录** → #24 及四轮表 `n_i`。**判据**：四轮差 <5%。

### 8.5 摩擦系数 μ1 / μ2 与方向相关性（#25–27）
- **μ1（滚动方向）**：小车沿**滚动方向**匀速拖动，弹簧秤读拉力 `F`，`μ1 = F/(mg)`。或用**滑行减速法**：推一下让它自由滑行，测减速度 `a`，`μ1 = a/g`（更简单，用手机录视频 + 地面标线）。
- **μ2（辊子自由方向）**：把车**横着拖**（辊子自由方向），同法测 `μ2`。
- **方向相关性**：比较 `μ1` 与 `μ2`，`μ1>μ2` 即方向相关。
- **记录** → #25、#26、#27。**说明**：URDF 里 `μ1`、`μ2` 两个值都要填，只填一个 μ 横移会明显偏。

## 9. D 组 · 标定常数（必需参数 #28–32，当前全空）

### 9.1 有效几何常数 `(l_x+l_y)/R_eff`（#28）
- 由步骤 5 的 `R_eff` 与已知 `l_x=68.75`、`l_y`（前 60 / 后 59）算出，取四轮一致值 → #28。

### 9.2 陀螺仪 yaw 标度因数 `k_yaw`（#29）
- **步骤**：把车放在地面标线/转台上，**精确旋转已知角度** `ψ_true`（如用地砖 90°、或标记四点 360°）；同时读 IMU 积分航向 `ψ_imu`。`k_yaw = ψ_true / ψ_imu`。
- **判据**：正、反各做 3 次取平均，离散 <2%。
- **记录** → #29。

### 9.3 陀螺仪角速度零偏 `b_z`（#30）
- **步骤**：小车**静置 60 s**（不碰任何东西，含上电预热 1–2 min），记录 yaw 角速度读数的均值（不可用积分角度，要用角速度原始值）。
- **记录** → #30（单位 °/s）。**说明**：GY-25T 无磁力计，航向靠积分必然漂移，`b_z` 每次上电都要重标或开机静止标定。

### 9.4 IMU 输出率 `f_imu` 与接口（#31、#32）
- **f_imu**：手册值，或从串口时间戳统计每秒帧数。
- **接口与波特率**：记录 UART/I2C、波特率、帧格式（附录 #47）。
- **记录** → #31、#32。

## 11. F 组 · 标定与耦合验证（必需参数 #38–42，当前全空）

### 11.1 里程计航向 vs IMU 航向 漂移率 `ḋ_ψ`（#38）
- **步骤**：低速直行 2 m，同步记录**编码器航向**（由四轮差算）与 **IMU 航向**；`ḋ_ψ = |Δψ_enc − Δψ_imu| / 里程`。
- **判据**：越小越好；这决定「走得直」。
- **记录** → #38（°/m）。

### 11.2 横移交叉耦合系数 `ε_xy`（#39）
- **步骤**：给**纯横移**指令走 1 m，量实际纵向位移；`ε_xy = |Δx| / |Δy| × 100%`。
- **记录** → #39。

### 11.3 电机阶跃时间常数 `τ_m`（#40，同时填四轮表 `τ_m_i`）
- **步骤**：给某轮一个**阶跃占空比**（如 0→60%），用编码器带时间戳记录转速；取到达稳态 63% 的时间。
- **判据**：四轮 `τ_m` 近似一致（差 <30%）；用于定速度环带宽与做前馈。
- **记录** → #40 及四轮表。

### 11.4 原地旋转实测转向中心 `(x_r, y_r)`（#41）
- **步骤**：地面铺纸/贴标线，低速**原地旋转 360°**，用手机录像追踪车体参考点轨迹；不动的那一点即转向中心，量它相对几何中心的偏移。
- **判据**：偏移远小于车长则合格（见「一次性检查」#22）；明显平移 → 用此修正原点。
- **记录** → #41。

### 11.5 IMU 快速旋转响应滞后 `τ_imu`（#42）
- **步骤**：给一个**快速旋转**指令，同步录 IMU 航向与编码器航向，比较两条曲线的相位/延迟。
- **记录** → #42（ms）。
